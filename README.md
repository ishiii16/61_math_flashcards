# Math Flashcards Repair Lab

This project is an interactive mental arithmetic flashcard game using **Pygame**. It introduces students to mathematical operation parsing, string formatting vs arithmetic evaluation, custom text-box input components, and feedback messaging within an object-oriented codebase.

---

## What's Provided

A working Math Flashcards game with:

- Dynamic flashcard generation featuring randomized operands and operators (`+`, `-`, `*`)
- Subtraction safety logic preventing negative outcomes during card generation
- A custom numeric `TextBox` widget supporting cursor input, digit entry, and backspace
- Input submission via the `Return` / `Enter` key or clicking the `SUBMIT` button
- Live score and attempt tracking with color-coded feedback messages

It had **one deliberate bug** and **three optional features** left as tasks to implement. All four tasks have now been completed using an LLM as a pair-programming partner.

### **An LLM (Claude / ChatGPT) was used as the debugging and pair-programming partner for this lab.**

## Getting Started

### Setup

1. Make sure you have Python 3.10+ installed.
2. Install dependencies:

```bash
pip install pygame
```

3. Run the game:

```bash
python main.py
```

**Controls:** Type numeric digits into the text box and press Return (or click SUBMIT) to submit your answer.

## Tasks Completed

All four tasks have been implemented in `game/game_engine.py`.

### ✅ Task 1: Fix the string concatenation calculation bug

**Bug:** `compute_expected_answer()` was returning `int(f"{self.num_a}{self.num_b}")` (string concatenation) instead of performing actual arithmetic. For example, `7 + 5` returned `75` instead of `12`.

**Fix:** Refactored `compute_expected_answer()` to use a proper conditional block that evaluates `+`, `-`, `*`, and `//` based on `self.operator`.

---

### ✅ Task 2: Per-question countdown timer bar

A 10-second visual timer bar is displayed below each flashcard:

- The bar smoothly drains from **green → yellow → red** as time runs out.
- A seconds label (`Xs`) is rendered to the right of the bar.
- On timeout: the attempt is counted as failed, the streak resets, a **"TIME'S UP!"** message is shown in magenta, and the next card loads automatically after 1.8 seconds.

---

### ✅ Task 3: Consecutive correct streak multiplier

A streak counter tracks consecutive correct answers:

| Streak | Multiplier |
|--------|------------|
| 0–2    | ×1         |
| 3–4    | ×2         |
| 5+     | ×3         |

- A streak indicator (`Streak: N  xM`) appears in the HUD when the streak is ≥ 2.
- The streak and multiplier reset to zero / one on any wrong answer or timeout.

---

### ✅ Task 4: Division operator with guaranteed whole-number results

The `/` operator has been added to `generate_new_card()`. Division cards are generated by:

1. Picking a random **divisor** (2–9) and **quotient** (2–12).
2. Multiplying them to produce the **dividend** — guaranteeing a clean integer result every time.

---

## Expected Behavior

- Flashcards present arithmetic problems using `+`, `-`, `*`, or `/` with random numbers.
- Typing the correct arithmetic answer increments the score (multiplied by the active streak bonus) and moves to the next card.
- Submitting an incorrect answer displays the expected value, resets the streak, and clears the input box.
- Submitting an empty input prompts the user without counting as a failed attempt.
- Running out of time counts as a failed attempt, resets the streak, reveals the correct answer, and auto-advances after 1.8 seconds.
